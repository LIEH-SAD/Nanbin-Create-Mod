# Nanbin Create Mod Description
Nanbin Create Mod is a Minecraft Mod based on Minecraft Transit Railway

## Main Feature
- JavaScript RailwaySign Support
- ChongQing Railway Transit Object
- City Create Function
- RailwaySign Copy Support

## Third-party Code

This project uses source code from [CRT-Sign-Web-Editor](https://github.com/PrisamaX0124/CRT-Sign-Web-Editor) by [PrisamaX0124](https://github.com/PrisamaX0124).
