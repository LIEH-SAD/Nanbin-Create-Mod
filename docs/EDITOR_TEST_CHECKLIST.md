# CRT 导视牌编辑器：实机验证清单

> 用途：当前环境无法启动 Minecraft 客户端，以下用例需要进游戏人工过一遍。
> 相关文档：[WEB_EDITOR_SPEC.md](WEB_EDITOR_SPEC.md)（网页规格）、[EDITOR_MODULE_CONTRACTS.md](EDITOR_MODULE_CONTRACTS.md)（模块契约）、[EDITOR_GAP_ANALYSIS.md](EDITOR_GAP_ANALYSIS.md)（审计与修复记录）。

## 0. 进游戏前的准备
- 确认构建：`.\gradlew.bat :fabric:1.20.1:build` 或对应版本（本次开发以 fabric 1.20.1 为基准）。
- 建一个测试世界，放一段 MTR 车站（有 >1 条线路、至少 2 个站、有出口和站台），并放一块 CRT 铁路指示牌（手持刷子可编辑）。

## 1. 打开编辑器
1. 手持刷子右键 CRT 铁路指示牌 → 出现**浅色三栏**编辑器（左元素卡片 / 中画布 / 右属性）。
2. 界面无粉屏/崩溃；关闭后其他玩家能看到牌面变化（多人测试）。

## 2. 元素与布局
1. 左栏点「方向图标 / 服务图标 / 双语文本 / 大文本 / 数字线路 / 文本线路 / 出入口 / 出口 / 空白」分别添加 → 画布出现对应元素。
2. 点击选中（蓝框）、Ctrl 多选、Shift 范围选择；Delete 删除（元素删除为二次确认）。
3. 拖拽元素在行内排序、跨行移动；画布上选中元素旁出现浮动工具条（◀ ▶ 复制 删除）。
4. 拖拽选中元素左右边缘的内边距点 → 元素间距变化，撤销是一步。
5. 行控件：添加行、上移/下移/删除行、行背景色；多行牌的预览与世界渲染一致。
6. 右栏「标识牌设置」：宽度格数 1–15、动态宽度、行高、锁定宽高比、背景色、灰框宽/色 → 预览即时变化。

## 3. 元素属性
1. 每种元素选中后右栏字段齐全（文本/颜色/背景色/对齐/内边距/粗体；箭头方向与粗细；线路列表增删改；出入口编号；图标网格与旋转；空白宽度）。
2. 改颜色/字号/内边距后画布预览与世界渲染保持一致。

## 4. MTR 数据联动（重点）
1. 选中「双语文本」→ 数据绑定选「车站」→ 点「选择…」→ MTR 选择屏选中本站（可多选换乘站）→ 元素显示真实站名（中文行 + 英文行）。
2. 选中「数字线路」→ 绑定「多线路」→ 选择 MTR 线路 → 元素显示真实线路色条 + 线路编号；文字颜色属性生效。
3. 出口元素绑定出口 → 显示出口字母；站台元素绑定站台 → 显示站台名；大数字绑定「下一站/上一站」→ 显示相邻站名。
4. 在 MTR 里给线路改名/换色 → 回到牌面前，最多 ~1 秒后内容自动更新（内容指纹变了会立即重烘）。

## 5. 编辑历史与剪贴板
1. 撤销/重做（Ctrl+Z / Ctrl+Shift+Z，按钮也可）能恢复布局与选择集附近的编辑。
2. 复制/剪切/粘贴（Ctrl+C/X/V）：同行粘贴、跨行粘贴；粘贴后元素 id 不冲突。
3. 关闭编辑器再打开，内容仍在（NBT 保存）。
4. 底栏整牌四按钮：复制整牌 → 打开另一块 CRT 牌 → 粘贴整牌（内容整体替换，Ctrl+Z 可撤销）；清空整牌需点两次确认。

## 6. 左栏「CRT 预设」分类
1. 滚动到「CRT 预设（文字牌）」：48 张左右卡片有真实缩略图（图标+文字的旧文字牌），不是占位图。
2. 点卡片生成 icon 元素（渲染与世界里的贴图一致）；拖到画布/行也能插入。
3. 首帧约 20~50 张小贴图上传，不应卡顿；滚动来回后卡片仍显示。

## 7. JS 样式（整牌脚本渲染）
1. 右栏「标识牌设置 → JS 样式」出现脚本列表（含「无（自由布局）」）；选择 `crt_station_entrance` 后画布按脚本渲染、出现「JS 样式：…」角标。
2. JS 模式下点画布/拖元素无效（提示先切回「无」）；切换回「无」后元素仍在可继续编辑。
3. 「JS 数据…」打开 MTR 数据选择屏，选择线路/车站/出口保存后，牌面内容刷新（最多 ~1 秒）。
4. 旧存档 JS 风格牌（`crt_js_style_*`）：打开编辑器 → 自动识别为 JS 样式；不改动关闭时世界渲染保持 JS。
5. 删除/禁用脚本后重新打开：退回普通布局渲染，不崩溃。

## 8. 存档兼容
1. 旧存档（只有 signIds 的 CRT 牌）：打开编辑器 → 自动转成布局预览（视觉近似旧牌）；**不改动直接关闭**不应改变世界渲染。
2. 旧牌编辑后再保存 → 世界渲染切到布局渲染，内容与预览一致。
3. JS 样式旧牌（`crt_js_style_*`）：打开编辑器会转成布局的 JS 样式；不改动关闭时世界渲染仍按 JS（布局数据里有 jsStyle）。
4. 旧牌渲染 fallback 仍保留：未编辑过的旧牌在移除 fallback 前始终可正常显示。

## 9. 性能
1. 同屏放 10+ 块布局指示牌：帧率不应明显下降（静态牌 30s 才重烘，内容变化立即重烘）。
2. 超大牌（15 格 + 多行 + 长文本）：不卡死、不 OOM；贴图分辨率自动下降。
3. JS 样式牌：脚本烘焙约 1 秒刷新一次（MTR 数据变化时），大牌不卡顿。

## 10. 已知偏差（不是 bug）
- 图标元素不做单色换色（本 mod 图标是彩色 signs.json 贴图）。
- 站台/出口的双语排版与网页项目略有简化。
- `crt_signs.json` 现在只保留 49 个「文字牌预设」；27 个与网页图标重复的基础图标已合并进代码内置表 `CRTBuiltInSignIcons`（旧存档渲染、网页图标映射都会加载它们，行为不变）。
- platform.html（站台吊板 / 线路图编辑器）尚未移植（如有需要可另开一轮）。
